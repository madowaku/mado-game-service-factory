# Sakuga Interaction Lab M0.1

An isolated, offline proof of concept using three **unmodified** MIT-licensed Sakuga VFX web components.

Run: `python -m http.server 8000 --bind 127.0.0.1 --directory services/incubation/sakuga-interaction`

Open: `http://127.0.0.1:8000/`

The Run simulation button drives an eight-step *fake* task. Completion indicates only that the local animation reached its end. It does **not** indicate any real build, test, shipping permission, or game evidence. The checkbox demonstrates a form-associated value and a visible review requirement. Reset cancels progress.

See `docs/MGSF_SAKUGA_INTERACTION_LAYER_M0_1.md` for scope, known limits and the evidence gates. Vendor source and license metadata are in `vendor/UPSTREAM.md`.
